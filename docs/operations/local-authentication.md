# 本地密码认证运维说明

本说明覆盖当前交付的本地密码登录、首次登录改密和密码恢复。当前 SMTP 与应用基础 URL 通过环境变量配置；待系统设置功能实现后，再迁移到对应的系统设置模型。

## 配置

复制 `.env.sample` 为 `.env`，并设置以下值：

- `ROSEIOT_JWT_HMAC_SECRET`：独立的 Base64 编码密钥，解码后至少 32 字节。可使用 `openssl rand -base64 32` 生成。不要在环境间复用，也不要提交密钥。
- `ROSEIOT_ACCESS_TOKEN_TTL`：访问令牌寿命，默认 `10m`。
- `ROSEIOT_REFRESH_TOKEN_TTL`：刷新凭证寿命，默认 `30d`。当前切片签发并持久化刷新凭证；刷新和会话自助管理由后续切片实现。
- `ROSEIOT_PASSWORD_RESET_TOKEN_TTL`：邮件重置凭证寿命，默认 `30m`。
- `ROSEIOT_PASSWORD_MINIMUM_LENGTH`：最小密码字符数，默认 `12`。BCrypt 输入最多支持 72 个 UTF-8 字节，超出请求会被拒绝。
- `APP_BASE_URL`：密码重置链接使用的站点 URL，默认 `http://localhost:8080`。
- `MAIL_HOST`、`MAIL_PORT`、`MAIL_USERNAME`、`MAIL_PASSWORD`、`MAIL_FROM`：SMTP 连接和发件人设置。本地默认指向 `localhost:1025`；可接入本地邮件捕获服务。

应用启动时验证 JWT 密钥和认证配置。生产部署应将凭证放入部署平台的密钥管理服务，并为 SMTP 配置 TLS 与认证信息。

## 防暴力尝试限制

速率计数保存在 PostgreSQL 中，因此同一数据库上的多个应用实例共享限制。登录按规范化邮箱计数：15 分钟内最多 5 次失败尝试；一次成功登录清除该邮箱计数。超限返回 `429` 和 `Retry-After`。密码重置请求每个规范化邮箱每小时最多处理 3 次；超限仍返回与普通请求相同的通用成功响应。

旧于两天的计数记录每小时清理一次。速率键只保存规范化邮箱的 SHA-256 摘要，不保存明文邮箱。

## 凭证处理

访问令牌使用 HS256 签名并以 JSON Bearer 形式返回；每个受保护请求都会检查关联会话仍有效。刷新凭证和密码重置凭证只以 SHA-256 摘要保存。密码重置明文凭证仅进入邮件链接；重置完成后，该用户所有既有会话立即撤销。密码错误与未知邮箱的登录错误保持一致，密码重置请求始终使用通用响应。

自动化集成测试替换邮件发送边界，不连接真实 SMTP；测试使用 Testcontainers PostgreSQL 验证持久化限流和会话撤销。
