# Triage Labels

Engineering skills refer to five canonical triage roles. Use the corresponding
GitHub label shown below.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical role, apply the corresponding GitHub label.
Change this mapping instead of creating duplicate labels if the repository
later adopts a different vocabulary.
