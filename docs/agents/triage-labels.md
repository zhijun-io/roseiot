# Triage Labels

The skills use five canonical triage roles. This file maps each role to its GitHub label.

| Label in mattpocock/skills | Label in GitHub | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, apply the corresponding GitHub label. The labels still need to be created in GitHub after this repository's remote is configured.
